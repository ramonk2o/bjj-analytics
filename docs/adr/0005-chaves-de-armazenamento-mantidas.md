# Chaves de armazenamento mantidas da versão antiga

As chaves do `localStorage` (`jja-settings`, `includeCurrentWeek`, `collapsed:*`) e o IndexedDB `jiu-jitsu-report` são os da versão de arquivo único (`legacy/bjj-analytics.html`), para quem atualiza não perder as configurações nem a pasta escolhida. Renomear qualquer uma exige migrar o que já está salvo.
